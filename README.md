# 🪓 Hangman (Python Edition)

Welcome to my text-based Hangman game built in Python!  
This project was created as a beginner-friendly way to practice core Python concepts like loops, conditionals, string manipulation, and user input.

---

## 🎮 Gameplay Overview

- Randomly selects a word from a list.
- Provides hints to the player.
- Tracks incorrect guesses and displays ASCII-based hangman stages.
- Player wins by guessing the full word before the hangman is complete.

---

## 🧠 Features

- Clean, beginner-friendly Python code.
- ASCII art for visual progress.
- Hint system for each word.
- Tracks guessed letters and incorrect attempts.
- Option to play again or exit after finishing a round.

---

## 🛠 Technologies Used

- Python 3
- Standard Python libraries: `random`, `os`
